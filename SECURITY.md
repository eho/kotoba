# Security

## Reporting A Vulnerability

Please do not report security issues in public GitHub issues.

Use GitHub's private vulnerability reporting for this repository, or contact the
maintainer directly if private reporting is unavailable.

Include:

- affected package and version
- steps to reproduce
- expected and actual behavior
- impact and any known workaround

Do not include API keys, access tokens, secrets, private user data, or provider
credentials in reports.

## Supported Versions

Security fixes target the latest published package versions unless a maintainer
announces otherwise.
